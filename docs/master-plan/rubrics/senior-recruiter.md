# Senior recruiter rubric

Lens: a senior technical recruiter or hiring manager forming a judgment of the engineer from
the repository and the product in a few minutes. Criteria marked **C** are critical (see
[scoring](README.md#how-to-score)).

## 1 · Visual design (first impression)

- **C** The hero capture reads as a designed product, consistent with the portfolio identity.

## 2 · Dashboard UX (first impression)

- **C** The purpose of each screen is obvious without explanation; the gallery shows the
  redesigned overview, interactions and access views.

## 13 · Docs and showcase

- **C** README readable in under 60 seconds, tested with 2 non-technical people: what it is,
  hero capture, 3 engineering bullets, quick start.
- **C** Affirmative tone with a single "Scope and limits" section instead of repeated
  disclaimers.
- Real badges (CI, CodeQL, Scorecard, license, Node); rendered Mermaid diagrams; gallery moved
  to `docs/gallery.md`.
- Community files present (`CODE_OF_CONDUCT.md`, `SUPPORT.md`, `CODEOWNERS`, issue templates,
  `CHANGELOG.md`); repository homepage links to the portfolio case study.
- One product name everywhere ("Portfolio Backoffice").
