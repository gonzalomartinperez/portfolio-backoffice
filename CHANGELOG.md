# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/). Entries are generated by release-please from
Conventional Commit titles merged to `develop` (sections Added, Changed, Fixed, Removed,
Security). The first release after the refactor is 2.0.0 (master plan PBO-D14).

The master refactor (milestones M1-M7) integrates on `develop` (see
[progress](docs/master-plan/progress.md)); `main` and 1.0.0 are unchanged until the M7 promotion.
