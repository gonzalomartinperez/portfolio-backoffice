# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/). Entries are curated by hand under
`## [Unreleased]` from Conventional Commit titles merged to `develop` (sections Added, Changed,
Fixed, Removed, Security). A release PR moves them under `## [X.Y.Z] - YYYY-MM-DD` and bumps
`package.json`; `release-tag.yml` tags `vX.Y.Z` when that commit reaches `main` (OD-78).
The first release after the refactor is 2.0.0 (master plan PBO-D14).

The master refactor (milestones M1-M7) integrates on `develop` (see
[progress](docs/master-plan/progress.md)); the next version section is 2.0.0 at the M7 promotion.
